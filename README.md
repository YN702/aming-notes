# 阿铭笔记（aming-notes）

一个纯本地运行的网页笔记应用，**单文件、零依赖、双击即用**。

## 这是什么

一个 HTML 文件（`notes.html`），用浏览器打开就是一个完整笔记应用：

- 新建 / 重命名 / 删除笔记
- 搜索
- 自动保存

数据存在浏览器的 localStorage 里，**不上传任何服务器**。

## 怎么用

1. 下载 `notes.html`
2. 用 **Edge** 或 **Chrome** 打开（不建议国产浏览器，部分新功能支持不全）
3. 开始写

## 备份功能（重要）

笔记存在浏览器 localStorage，**清浏览器数据会把笔记一起清掉**。所以内置了三个备份按钮（右上角）：

| 按钮 | 干什么 | 建议 |
|------|--------|------|
| 备份 | 全部笔记打包下载成 JSON 文件 | 定期点一下，存网盘/U盘 |
| 恢复 | 把备份文件导回来（按时间去重合并） | 误删/丢数据时用 |
| 自动备份 | 选一个文件夹，以后每次改动自动写一份 | **设置一次，一劳永逸** |

> 注意：localStorage 按浏览器隔离。换浏览器打开 = 换了一个"抽屉"，笔记不会跟过去。固定用一个浏览器，或用"备份/恢复"迁移。

## 数据安全

- 笔记只存在你本机的浏览器里，不上云、不联网同步
- 别在笔记里存 API Key、密码等敏感信息——localStorage 不是保险箱

## 技术栈

纯 HTML + CSS + JavaScript，图标用 [lucide](https://lucide.dev/) CDN，无构建步骤。
